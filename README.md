# sketchy-direct-imaging-contrast-plots
This repository pulls together a few different code tools to try to put exoplanet direct imaging in context. It's *very sketchy*. On 7 May 2026, Zach Berta-Thompson quickly hacked the thoughtfully crafted direct imaging flux ratio visualization code (https://github.com/nasavbailey/DI-flux-ratio-plot) into a notebook to make some plots for a talk. 

Please consider yourself are super duper extremely strongly encouraged to go directly to the original source to get contrast curves or make your own contrast plots. I put this up here just to make it a little easier to share with a few folks, but please be respectful and careful of the amazing work V. Bailey did in putting together that original code. 

### Usage 

You'll need to install [exoatlas](https://github.com/zkbt/exoatlas) with something like `pip install exoatlas`. Once it's installed, the notebook `exoplanets-direct-imaging.ipynb` should run straight through and make a bunch of plots. Good luck!?
